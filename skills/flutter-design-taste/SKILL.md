# Flutter Design Taste
Start by defining the product personality, audience, usage moment, and visual direction. Do not use the default Flutter template. Create a short text-based mood board, then choose:
- One clear visual direction instead of mixing multiple styles.
- A primary color, supporting color, and semantic success, warning, and error colors.
- A clear relationship between display and body typography.
- A consistent spacing, border, and shadow scale.
- One focal point and one clear primary action per screen.
Avoid decoration without a purpose, random gradients, excessive glassmorphism, inconsistent icons, and low-contrast gray text. Deliver `DESIGN_DIRECTION.md` before building components.
