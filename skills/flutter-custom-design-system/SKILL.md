# Flutter Custom Design System

أنشئ مصدرًا واحدًا للهوية: `AppColors` و`AppTypography` و`AppSpacing` و`AppRadii` و`AppShadows`، ثم اربطها بـ `ThemeData` و`ColorScheme` بدل نشر قيم خام داخل الشاشات.

أنشئ مكونات قابلة لإعادة الاستخدام مثل `AppButton` و`AppCard` و`AppTextField` و`AppEmptyState` و`AppErrorState` و`AppLoadingState`. عرّف حالات default وpressed وfocused وdisabled وloading وerror. اجعل المكونات تعمل في Light/Dark وRTL، واختبرها بأطول نص متوقع.
