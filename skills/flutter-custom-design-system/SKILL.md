# Flutter Custom Design System
Create a single source of truth for the visual identity: `AppColors`, `AppTypography`, `AppSpacing`, `AppRadii`, and `AppShadows`. Connect them to `ThemeData` and `ColorScheme` instead of scattering raw values across screens.
Create reusable components such as `AppButton`, `AppCard`, `AppTextField`, `AppEmptyState`, `AppErrorState`, and `AppLoadingState`. Define default, pressed, focused, disabled, loading, and error states. Make the components work in light mode, dark mode, and RTL, and test them with the longest expected text.
