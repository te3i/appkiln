AAppKiln
Mobile app building skill

From a small idea to a buildable app.

AppKiln is a universal AI skill that connects five design modules, turns your idea into a polished Flutter or Swift MVP, and delivers a verified APK or IPA through GitHub Actions.

Open repositoryRead the skill
01 / Design

Visual direction, design system, RTL and dark mode support, and clear screen states.

02 / Build

Flutter or Swift/iOS with an extensible structure, checks, and a polished user experience.

03 / Deliver

GitHub repository and workflow that builds the requested APK or IPA and verifies its artifact and checksum.
