# مثال سريع

## الطلب

أريد تطبيق Flutter عربي لأصحاب LiveContainer يفحص IPA قبل التثبيت، يوضح VPN وWidgets وPush وJIT، ويحفظ الملفات ويصدر تقريرًا. استخدم أحدث تصميم UX/UI، ارفع المشروع إلى GitHub وابنِ IPA.

## السلوك المتوقع من AI

1. يسأل: Flutter أم Swift؟ إذا كانت Flutter محددة يبدأ.
2. يقرأ وحدات التصميم الخمس.
3. ينشئ `DESIGN_DIRECTION.md`.
4. يبني MVP مع حالات الخطأ والتحميل والفراغ.
5. يضيف Files integration ونسخًا محليًا للملف.
6. ينشئ workflow على macOS.
7. يراقب البناء ويصلح الأخطاء.
8. يسلم GitHub URL وActions URL وIPA وSHA-256.
